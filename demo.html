Part 1 — Character options

Three hand-built SVG characters. No libraries, no image files — each is roughly 40–70 lines of inline SVG plus CSS keyframes. They react to your cursor, and you can trigger the greeting manually with the buttons.

A · "Ori" the guide

~0 KB · eyes follow cursor
Hi, I'm Sreya 👋

Friendliest of the three. Reads as a mascot — charming, but the furthest from a buttoned-up analyst tone.

B · Node assistant

~0 KB · most on-brand
Let's look at the data.

Echoes the node/network motif already in your project banners. Alive and personable without being a cartoon — my pick for a BA portfolio.

C · The walker

~0 KB · walks + waves
Hello! 👋

Closest to "walking around". Most attention-grabbing, and the one most likely to pull focus from your content — best used sparingly, e.g. once in the hero.

Notes on cost & risk

0 dependencies no build step both themes reduced-motion safe character choice pending

Everything above is vanilla SVG + CSS + a little JS, matching how index.html already works. Dropping any of these into the live site means appending one self-contained IIFE to script.js, a block of CSS, and some markup — the same additive pattern your existing features use. Each guards on element presence, so a missing node no-ops instead of throwing.
